# Sentinel Zero services page

The original services page was stored in a file named `SSAG`, so it was not the site's standard homepage. A root `index.html` has now been added so GitHub Pages can serve it as the homepage.

The page describes services and clarifies that AI outreach, shared CRM records, and follow-up alerts only work after the required provider and data connections are configured and verified. It does not itself run those services.

Use this repository's `AGENTS.md` for future work. Explain progress and technical terms in everyday language.
